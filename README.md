This web application is a Zerodha clone that was created as a side project under the supervision of Apna College. To better align with the current layout and features of the official Zerodha website, I've made substantial changes to both the frontend and backend.
🔧 Features:

    ✅ User Authentication (Login / Signup)

    📉 Real-time Dashboard (Built with React.js)

    🛒 Order Placement – Orders get stored in MongoDB

    📁 Holdings – Displays demo holdings data from the database

    💡 Responsive UI updated as per Zerodha’s latest design

    🔗 Frontend-Backend connectivity via Express.js API

🛠️ Tech Stack:

    Frontend: React.js, CSS

    Backend: Node.js, Express.js

    Database: MongoDB

    Tools: Postman (for API testing), MongoDB Compass

📦 How It Works:

    Users can place orders, and each order is saved in MongoDB.

    The dashboard is dynamically connected to the database to show real-time updates.

    Holdings section fetches and displays demo portfolio data from the database.

🚀 Purpose:

This project was created to deepen my understanding of MERN stack development by replicating a real-world trading platform. It also gave me hands-on experience with API development, database integration, and UI refinement.
